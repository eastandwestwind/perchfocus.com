Perch beta

What’s new in Perch

Changes in each version of the app. Perch updates itself, so you’ll see these when you click Install and relaunch.

0.1.9 28 October 2026

New

  • Wait-for steps. Add a step like “wait for <PR link> to be merged” or “merge dev in once #812 lands”, and Perch watches that PR for you. Until it lands, the context waits on it instead of nagging you about the CI it blocks. When it does, Perch tells Claude to carry on, or tells you if the wait was yours. Approved and CI green work too.
  • Claude’s scheduled check-ins. When Claude sets itself a reminder to look again later, the context stays with Claude until then, and Perch keeps the reminder alive if the session restarts.
  • Hide merged PRs. Merged and closed PRs fold behind “Show N merged” in the side panel.
  • Everyone gets a color. Each teammate keeps their own color across cards, steps, and PRs, and CI, the merge queue, and PRs a context waits on show in blue.

Improved

  • A wider, calmer quiet scene with hills, drifting clouds, and a crescent moon at night, matching the greeting’s time of day. It moves for a little while, then holds still so it uses no energy.
  • Much lower energy use overall. Chat reads only what’s new in a conversation, and PR checks run several GitHub lookups at once, so new reviews and CI results show up sooner.
  • Review comments on draft PRs now count as your move.
  • Replies on Jira tickets a context only mentions reach you when someone answers your comment.
  • PRs in GitHub’s merge queue show “In merge queue”, and failures in checks that aren’t required no longer read as CI failed.
  • New installs keep notifications on screen until you deal with them. To change yours, open System Settings, then Notifications, then Perch.

Fixed

  • A reply you dismissed no longer comes back on its own, and a background shell keeps a context on “Claude is working” even after you’ve seen the reply.
  • Permission requests from Claude’s background agents and workflows always reach you.
  • Two contexts no longer pass the same PR back and forth when one of them only mentions it.
  • A step to merge a PR counts as done once the PR merges.
  • The side panel scrolls from anywhere, and long links in steps wrap.
  • Perch’s background helper no longer shows up in the Dock.

0.1.8 27 October 2026

New

  • Answer Claude from the notification. Permission banners show what Claude wants to run, with Allow and Deny. “Claude replied” banners take a reply right in the banner. Perch only presses a key if Claude is still showing that same prompt, and opens the context otherwise.
  • Permissions in Chat. When Claude asks for permission, Chat shows the command with Allow and Deny, so you don’t have to switch to Terminal.
  • A quiet dashboard. When nothing needs you, the Perch bird rests on its branch under a sky that follows the time of day, and falls asleep at night. A line underneath says how long Claude worked today and how often it checked in with you. Your contexts are one click away.
  • While you were away. Come back after a long break and the dashboard opens with what moved: PRs merged, approved, or reviewed, and how long Claude worked on each context.
  • Hand-off notes. Copy a short Markdown summary of any context, with where it stands, what’s done, what’s next, its PRs, and its links, ready for Slack, a ticket, or standup. Find it in the ⋯ menu or at the bottom of the side panel.
  • Install with Homebrew. brew install --cask perch after tapping eastandwestwind/tap. The cask updates with every release.

Improved

  • One “In good hands” group on the dashboard for everything that isn’t your move, whether Claude, CI, or a teammate has it.
  • PR cards show who approved separately from comments still to address, and the toolbar says what to do in a few words, like “Address review on #42”.
  • A review you’re doing counts as done once you approve or the PR merges, and Perch suggests archiving it.
  • A PR links to its context the moment Claude opens it, and PR links in a context’s title are tracked too.
  • While CI is still running, a PR waits on CI instead of asking you to fix an early failure.
  • The dark terminal is a softer grey.

Fixed

  • Answering a permission prompt in Terminal clears “needs permission” right away, even while the approved command is still running.
  • No more false permission asks when auto mode approves a request before it shows.
  • Claude’s background shells and helper agents keep a context on “Claude is working” instead of flipping it to waiting for you.
  • When Claude ends a long reply with a question, the context shows that question instead of a PR alert.
  • Merged PRs stop showing “Awaiting review” after you switch branches, and approvals count in repos that don’t require reviews.

0.1.7 26 October 2026

New

  • Drop screenshots and files. Drag them onto the Chat message box or into the terminal, and Claude gets the file. Names with spaces just work.

Improved

  • Perch knows better when it’s really your move. If Claude is still running something in the background, the context stays on “Claude is working” until it’s done. If Claude finished without asking anything and a teammate’s review comes next, it shows as waiting on them.
  • Notifications name the piece of work they’re about and say what happened in plain words, like “Claude replied” or “Claude needs your OK”.

Fixed

  • macOS no longer asks to install Rosetta for Perch. Perch now ships only Apple Silicon code.
  • Clicking a notification opens the context it’s about.
  • Archiving a context while its Claude session is running works from the context view again.
  • A context no longer says it’s waiting for you while Claude is still working on it, even when one of its PRs needs attention.
  • PRs you’re reviewing no longer show your own comments as threads for you to answer. They show as “You’re reviewing” and wait on the author.
  • No banner for the context you have open when you were just in Perch, even if your last click was in another app.
  • Long context titles shorten in the toolbar instead of squeezing the status next to them.

0.1.6 26 October 2026

New

  • Bring your Claude chats. Import chats from the Claude app on the web or desktop using Claude’s data export. Perch walks you through the export, picks it up from Downloads, and lets Claude suggest which of your projects each chat belongs to, so you only check and adjust. Each chat becomes a context with its own folder, and Claude reads the earlier conversation when you pick it up.
  • Projects. Group contexts into projects in the sidebar, by dragging or from the ⋯ menu. Contexts in the same git repo group together on their own.
  • Search. Find any context by title, ticket, notes, status, links, or PRs from the dashboard or sidebar. Press ⌘K.
  • Azure Boards. For teams on Azure DevOps instead of Jira: work item status, new comments, and work assigned to you, through Microsoft’s own az sign-in.
  • Model and usage in Chat. See which model a session runs, how full its context is, and how much of your 5-hour and weekly limits you’ve used, and switch models from next to Send.
  • PR stacks. PRs that build on each other show as one chain, with the next one to merge and anything blocking it.

Improved

  • New reviews and comments on a context’s PRs stay marked on its card and in the side panel until you’ve seen them.
  • Contexts whose steps are done and PRs merged suggest archiving themselves.
  • First launch is two clear steps: check your tools, then bring in your work.
  • A new app icon that fits macOS 26.

0.1.5 26 October 2026

New

  • Later. Set a context aside from its ⋯ menu, or drag it onto Later in the sidebar or dashboard. It moves to a collapsed group, stays quiet, and isn’t counted in the badge, while Claude, PRs, and tickets keep running. It comes back on its own when Claude needs permission or asks you something, or a PR needs you.
  • Archive. Archive replaces Delete in the context menu, and you can also drag a context onto Archive. The new Archive view lists finished contexts with search, Restore, and Delete. When a context’s PRs are merged and its ticket is done, its card offers a one-click Archive.
  • Undo. Moving, archiving, restoring, or deleting a context shows a short Undo.

Improved

  • Perch no longer shows banners or plays sounds while its window is in front, since the dashboard and sidebar already show what needs you.

Fixed

  • Permission prompts always alert you now, including prompts from Claude’s helper agents. Before, a context could sit on a prompt while Perch still said it was working.

0.1.4 25 October 2026

New

  • GitLab. Merge requests show their approvals, pipelines, and threads, and the dashboard lists merge requests waiting on your review. Connect it with the GitLab CLI’s own sign-in. It’s optional, and Perch never changes anything in GitLab.
  • Links that add themselves. When a Slack thread, Jira ticket, Confluence page, Google Doc, Notion page, Figma file, Linear issue, or Loom video comes up in a context’s Claude conversation, notes, or status, Perch pins it with a readable title. Remove one and it stays removed.
  • Open in your editor. The ⋯ menu opens a context’s folder in VS Code, Cursor, Zed, or another editor you have installed.

Improved

  • The dashboard is calmer. A greeting sums up what’s your move and names anything that needs you, idle contexts take one line each, and review requests and Jira tickets sit in tidy panels.
  • Links are tidier. Each one shows its tool’s icon, Confluence, Notion, and Figma links show the page’s name, Slack threads show the day they started, and copies of the same page are merged. Long lists group by tool with Show more.
  • Tickets that only come up in conversation no longer send comment notifications. Only a context’s own ticket and links you add yourself do.
  • Settings is split into General, Integrations, and Privacy & help tabs, and fits on screen.
  • First-run setup separates what’s required (Claude Code) from what’s optional, and you can skip it and come back from Settings.
  • A new context’s side panel explains what will appear there, and the Start a Claude session card is clearer.

Fixed

  • The side panel no longer shows Connect Jira for a moment while Jira is still loading.

0.1.3 25 October 2026

New

  • Jira. Contexts with a ticket key like PROJ-123 show the ticket’s title, status, and latest comment. You get a notification when someone else comments, and the dashboard lists tickets assigned to you with a Start context button. Connect it from the setup checklist using Atlassian’s own sign-in. It’s optional, and Perch never changes anything in Jira.
  • Send feedback from the app. The Feedback button, the sidebar, and the Help menu open a short form that can include a screenshot of the Perch window.
  • A ⋯ menu for each context. Rename, open its folder in Finder, or delete it from the ⋯ button in the toolbar, or by right-clicking a context.

Improved

  • Alerts are easier to spot and clear. A context that needs you gets an orange dot in the sidebar, the toolbar says why, and one Dismiss button clears it. Failing CI now reads “CI failed”.
  • The side panel is calmer. Empty sections stay hidden, and Add step, link, and note appear when you click +. The ticket and PRs sit together under Tracking.
  • Chat shows a Jump to latest button when you scroll up, and New reply if Claude answered meanwhile.
  • Clicking anywhere outside an add field closes it, and anything you typed is kept for next time.
  • One setting controls how often PRs and tickets are checked. Refresh them anytime with ⌘⇧R.
  • The dashboard’s settings button moved to the far right.

0.1.2 24 October 2026

New

  • One-click updates. When a new version is out, click Install and relaunch. Perch downloads it, checks it’s genuine, and restarts, and your Claude sessions keep running.

0.1.1 24 October 2026

New

  • Chat view. See your conversation with Claude as chat, with formatted replies and a message box, as an alternative to the terminal. If Claude asks whether to trust a folder, you can answer right in the chat.
  • A simpler New context. Name it, pick a folder, and start Claude in one step. Ticket keys in the name are detected for you.
  • Guided setup. Perch can install Claude Code for you, and you choose folders in Finder instead of typing paths.
  • Optional crash reports. Off unless you turn them on. Reports never include your prompts, terminal output, or code.

Fixed

  • Claude can always update a context’s status, even in folders outside your project.

0.1.0 24 October 2026

The first public beta: a dashboard grouped by whose move it is, notifications only when something needs you, next steps with owners, PR tracking, deep focus, sessions that keep running when you quit, and importing your existing Claude Code sessions.
