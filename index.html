Installing

  1. Download the disk image and drag Perch to Applications.
  2. Open Perch and sign in to Claude Code, and to GitHub if you want PR states.
  3. Allow notifications, then bring over your existing Claude sessions.

Requires the Claude Code CLI. The GitHub CLI is optional, for PR states.
