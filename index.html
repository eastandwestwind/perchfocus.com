Run several Claude Code sessions.
Know which one needs you.

Perch is a calm Mac home for parallel Claude Code work. Each piece of work gets its own context with its terminal, a short status summary Claude keeps current, its PRs, and its links. When something needs you, Perch tells you. When nothing does, it stays quiet.

Download coming soon macOS · Apple Silicon · free for up to 3 contexts

A dashboard that answers "where are we?"

Every context shows a two-line status summary Claude writes as it works, the open next steps, and the state of its PRs. You can read the whole board in ten seconds and know what moved.

Needs me, and only when it's true

Perch watches each session's hooks. Claude waiting for permission or finishing a turn, a PR with threads to answer, CI going red, an approval ready to merge: those land in Needs me and send one notification. Everything else waits.

PR review states that mean something

Not just "in review". Perch tells "needs my reply" apart from "addressed, awaiting re-review", and flags approved, red, and conflicted PRs, including ones opened from a worktree Claude created along the way.

Sessions that outlive the app

Claude runs in a small background host, so quitting or updating Perch never ends a session. Relaunch and every terminal is exactly where you left it.

Deep focus

One click mutes every other context. The frame turns violet, the dashboard is out of reach, and only the work in front of you can notify. Leave when you choose to.

Everything for one piece of work, in one place

The real Claude Code CLI in a terminal, with your plugins, skills, and MCP servers. Beside it: the summary, a checklist you can edit, the PRs, pinned Slack and Jira links, the worktrees, and your notes.

Installing

  1. Download the disk image and drag Perch to Applications.
  2. The first time, right-click Perch and choose Open.
  3. Allow notifications when Perch asks, and import the Claude sessions you want to keep.

Perch needs the Claude Code CLI installed and signed in. The GitHub CLI is optional and powers PR states.
